# Release 0.142.4 (2026-07-19)

Expressive-TypeScript refactor of the production codebase and full test suite, plus a
type-safety hardening pass (no task tickets — Passes 6–7 of the expressive-TS effort).

## Added

- `isRecord()` type guard (`utils/type-guards.ts`) — narrows unknown parse output to a
  plain object record; adopted at the four previously-unvalidated `JSON.parse`/YAML
  boundaries (plugin-validator, source-fetcher, permission-checker, source-validator).
- `typedValues()` (`utils/typed-object.ts`) — type-safe `Object.values` over Partial
  records, retiring assert-style casts.
- `renderMetadataYaml()` / extended `renderAgentYaml()` / `renderAgentMd` re-export in the
  test content-generators — single source of truth for fixture metadata and agent files.
- Shared E2E infrastructure: `pollUntil`, `retryEnterUntil`, `writeAgentStubs`,
  `writeAgentFile`, and structural config-load helpers (`readSkillEntries`,
  `readAllSkillEntries`, `readConfigSkillIds`, `readAgentEntries`, `readSelectedAgents`)
  in `e2e/fixtures/dual-scope-helpers.ts`.

## Changed

- Production expressive-TS refactor across `src/cli` (~165 files): two-tier orchestrators,
  guard clauses, named predicates/transforms, extracted modules (`scope-predicates`,
  `install-base-dir`, `write-compiled-agents`, `require-marketplace`, `plugin-ref`,
  `validate-kebab-name`, `scope-diff`, `run-wizard-session`, `prompt-confirm`, …).
- Type-safety hardening: `typedEntries` over `groupBy` results (config-generator,
  config-types-writer), Zod schema-level typing for imported/local skill metadata
  (drops per-site casts), `getErrorMessage` adoption, redundant/double casts collapsed,
  boundary comments on all remaining deliberate casts (including the documented
  out-of-union placeholder categories in `metadata-keys.ts`).
- Test-suite expressive-TS refactor (~250 spec/infra files): factories and structural
  config loads replace hand-rolled parsers (YAML state machines, config-text regex
  extractors, a 55-line multi-strategy parser); shared arrange helpers replace
  copy-pasted rituals; static imports replace per-test dynamic imports; banner comments,
  debug console.log dumps, and `.toEqual`-on-objects swept; environment-conditional
  installation tests made deterministic via homedir isolation.
- E2E stability: `maxWorkers: 16` cap (PTY tests are load-sensitive at full
  parallelism); lifecycle tests now inherit the suite-level `retry: 2` instead of
  per-test `retry: 0` overrides.

## Fixed

- Plugin validation: a plugin.json containing a JSON array/string/number was previously
  accepted as a "manifest" and misbehaved downstream; it is now rejected (treated as an
  unreadable manifest).

## Removed

- `user-journeys/_diagnostic.test.ts` — scratch investigation file (all assertions were
  `expect(true).toBe(true)`).
