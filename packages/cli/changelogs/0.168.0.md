# Release 0.168.0 (2026-10-14)

A sub-agent can pin a Codex model, share links are seed version 6 only, the compile package's warnings reach the
terminal, and the editor takes the v6 design with named saves (EDITOR-09, EDITOR-95)

**Before you upgrade.** Version 6 is a clean break. A link or editor save minted before this release no longer loads;
re-share it to mint a current one. Once the worker is deployed, 0.167.0's `share` is refused.

## Added

### EDITOR-09 — Codex model pins, and the editor on the v6 design

- **A sub-agent can pin a Codex model.** An agent row in `config.ts` takes `codexModel` beside `model`: `gpt-6-astra`,
  `gpt-5.6-sol`, `gpt-5.6-terra` or `gpt-5.6-luna`, the ids `@openai/codex` 0.155.1 serves. `gpt-5.5` is left out
  because it refuses `max`. An unknown id is refused like an invalid `model`.
- **A Codex role file writes the pin** as `model = "<id>"` and `model_reasoning_effort` (the agent's effort, else its
  metadata's, else `medium`). A role without a pin is byte-identical to before. Claude ignores the field, so one
  `config.ts` serves both providers.
- **`init --from`, `edit` and `share` carry it.** `init --from` writes it on either provider, `edit` keeps it and
  lists `codex model <id>`, and `share` sends it. A link pinning an id this CLI does not offer installs without it,
  exit code unchanged, and warns: `Sub-agent '<agent>' asks for Codex model '<id>', which this version of the CLI does
not offer, so it runs on the session's model.`
- **The editor, on the v6 handoff.** Providers are step 01. Sub-agents are cards in step 03, with Codex models as
  toggles. Filters sit in the search field. The domain tabs slide an indicator and stick as a 3rem strip. Rail 05
  groups by domain or scope. Save opens a dialog to name the save, and names are unique across the grid.

### EDITOR-95 — a saved name the account already has

- A save made while signed out, whose name the account already lists, opens the Save dialog at sign-in with "Names
  must be unique." on the name field. Renaming saves it; cancelling keeps it waiting.

## Changed

- **Seeds are version 6 only.** `SEED_VERSION` is 6 and the decoder accepts nothing else. v5 links and saves are
  refused with the message to re-share, and the worker refuses v5 posts.

## Fixed

- **The compile package's warnings reach the terminal.** `package.json` declared `sideEffects: false`, so since
  0.161.0 the bundle dropped `compile-seat.ts`, the import that wires them. A stripped template delimiter, a selected
  id the marketplace does not carry, and an unoffered Codex model now warn.
