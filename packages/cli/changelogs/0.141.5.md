# Release 0.141.5 (2026-07-09)

`build marketplace` gains a `--name` override.

## Added

### `--name` flag on `build marketplace`

`build marketplace` derived the marketplace's `name` field verbatim from `package.json`'s
`name`, with no sanitization. Consumers whose `package.json` uses an npm scoped name (e.g.
`@agents-inc/skills`) got that scoped string written straight into `marketplace.json`, which
fails Claude Code's marketplace name validation (no `/`, `\`, `..`, or `.` allowed) — breaking
`claude plugin marketplace add` for that marketplace.

Added an opt-in `--name` flag that overrides `package.json`'s `name` for the marketplace
identity. Validated fail-fast against the same kebab-case rule `new marketplace` already
enforces (`validateMarketplaceName`), so an invalid override errors before anything is written
rather than reproducing the original bug. Omitting the flag preserves the exact previous
default behavior.

```
npx @agents-inc/cli build marketplace --name agents-inc
```

- `.ai-docs/agent-findings/2026-07-09-marketplace-schema-name-laxer-than-claude-code.md` —
