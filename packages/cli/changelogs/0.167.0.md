# Release 0.167.0 (2026-10-04)

`.claude-src/` is retired: nothing reads or writes it, and a run that finds it says to move it (CLI-913)

**What this release is.** The owner ruled that the CLI keeps no backwards support for the source folder's old name.
Since 0.165.0 new installs have used `.agents-inc/<provider>/`, and this release stops treating `.claude-src/` as an
installation at all.

## Added

### CLI-913 — `.claude-src/` is retired

- **Every run checks once for `.claude-src/`, in the project and in HOME.** When it finds one, it prints a single line
  before the command starts: `.claude-src/ is no longer supported (agents-inc now serves Claude and Codex). Move it to
.agents-inc/claude/.` The line goes to stderr and never changes the exit code.

## Removed

- **Reading and writing `.claude-src/`.** Every scope resolves to `.agents-inc/<provider>/` and nothing falls back to
  the old folder. That covers projects, the global install, and marketplace repositories that declared
  `.claude-src/config.ts`.
- **The two-source-folders write refusal.** With nothing reading the old folder, the second one can no longer compete.
  `compile`, `update`, `edit`, `share`, `eject` and `init` no longer check for it.
- **`doctor`'s legacy rows.** The Layout row names only the current folder. The "still on the old folder" warning, the
  two-folder failure, the "agent names the other folder" check and the list of registered projects still on the old
  folder are gone.
- **`uninstall` clearing both folders.** It now works on the one source folder.
- **The old name everywhere else.** The CLI spells `.claude-src` only in the startup line, and the shared compile
  package's `LEGACY_SOURCE_DIR` and `CLAUDE_SRC_DIR` exports are removed. Lint bans, drift scripts, tests, the
  reference docs and the site no longer mention it.

## Backlog

- CLI-920 (filed): in a folder with both a Claude and a Codex install, `uninstall` without `--provider` still asks
  which one to remove. Parked with Codex.
- CLI-921 (filed): cancelling an `edit --from` prints "Edit cancelled" and then "Error: Cancelled".
- CLI-908 and CLI-909 (deferred): `edit --from` will show the info table, at full width, with an overwritten marker.
- CLI-914 (deferred): honouring `CLAUDE_CONFIG_DIR` for the global install paths.
