# Release 0.149.2 (2026-08-04)

The repository was renamed, and the schema address moved with it

## Changed

### The JSON schema address follows the repository's new name

The repository is `agents-inc/agents-inc` now rather than `agents-inc/cli`. It holds the web configurator, the documentation site and the API worker alongside the CLI, so the old name had stopped describing what is in it.

The `$schema` line the CLI writes into every metadata file it generates points into that repository, so it moved too:

```
https://raw.githubusercontent.com/agents-inc/agents-inc/main/packages/cli/src/schemas
```

**Files generated before this release keep working.** GitHub redirects the old address, and that redirect chains — `claude-collective/cli`, two renames back, still resolves today. This was checked rather than assumed.

So there is nothing to do on upgrade. What changes is only the address new files are born with, and the reason to move it is that emitting an address which depends on a redirect is worse than emitting the current one. A redirect is a courtesy that lasts as long as nobody claims the freed name.

The 23 agent metadata files shipped inside this package carry the new address too.
