# Release 0.156.0 (2026-08-20)

The programme audits its own output, and a guard finds the defect every suite was blind to (CLI-535, CLI-539, CLI-545, CLI-548, CLI-550, CLI-565, CLI-585, CLI-586, EDITOR-48)

Two days spent almost entirely on whether what this repository already claimed was true. The accuracy programme re-derived 51 reference documents from source on the assumption that all of them were wrong, graded and pruned a 382-finding corpus to 112, and walked all 39 user journeys by hand. It then turned the same treatment on its own output: three audits, every finding re-verified by an agent forbidden from fixing it, and the fixes applied by someone else again.

The measurement that came out of it is the one worth keeping. Across roughly twenty agent dispatches, **every agent that checked a figure in its own brief found at least one wrong** — and none of it was caught by review. That is now a tracked investigation with its own plan rather than an anecdote.

Two guards were built rather than assumed, and both immediately earned their place. The drift checker learned to read a table's values and found five wrong cells in a table it had been reporting clean. The viewport guard found a warning that had been shipping invisibly for as long as the code path existed.

## Added

### CLI-586 — every wizard keypress asserts the frame fits the terminal

`TerminalSession` gained `linesAboveViewport()`, and `BaseStep.waitForWizardFooter()` now asserts the painted wizard screen is wholly on screen — so every interactive spec inherits the check at every keypress rather than one spec carrying it.

The first invariant drafted for it was structurally blind, and that is the part worth recording: a *baseline* on `viewportY` absorbs a constant overflow into the baseline. Proved by mutation — a root box built at `terminalHeight + 4` left the baseline form green across all thirteen tests and reddened the absolute form, which is the form that shipped.

It then reddened nine specs across five files, all losing the same three lines. See Fixed.

### CLI-585 — the drift checker reads a table's values, not only its keys

`check-enumeration-drift.ts` gained a pair-encoding mode: both sides emit `key = value` strings, so the existing comparison works unchanged **and** a swap of two values is detectable, which a values-only set cannot do. Three named refusals rather than a silent skip.

Proved on the defect that raised it — a table with five wrong display-title cells that the old key-only binding reported as agreeing and clean.

### CLI-565 — a document can bind a module's re-export surface

A new source shape reads both forms that were unreachable: re-exports carrying a module specifier, and those in a bare `export { … }` block. The design question the row demanded a ruling on is ruled and written into the reader itself — a locally-imported-then-re-exported name resolves to the export clause's own spelling, with nothing followed.

### CLI-535 — four of five binding gaps closed

The command roster as a filesystem walk; `unwrap()` reading through `satisfies`; a list split across several tables under several headings; and the three barrel tables, bound through the directory reader. The registry went from 6 rows to 62. Still open: `static` class members, so no command's flag list is registerable.

### EDITOR-48 — the editor's Playwright suite refuses the network

The `page` fixture routes the worker and both GitHub origins, aborts, records, and asserts the recorded list empty at teardown. Installing it found four more live instances the same day, all green and all reaching the config mint unstubbed.

## Changed

### CLI-545 — the accuracy programme

Three phases. The worklist across sixteen briefs, where every one of the sixteen executing agents corrected something in its own brief. All 39 user journeys walked by hand, finding two shipped defects that 6,777 unit, 810 e2e and 297 Playwright tests were all blind to — both invisible for the same reason, each suite having built both ends of its comparison with the same producer. Then 294 findings triaged, 131 deleted, and a guards-are-not-features ruling that returned 54 parked items to scope.

### CLI-550 — the vendored catalogue says which matrix it is

`schema.ts` became `built-in-matrix.ts`, and the built-in agent roster became vendored data the wizard reads rather than a literal in a component body.

### CLI-539 — the standards the findings were blocked on

Ten findings had been waiting on rules nobody had written. Nine landed as rules; the tenth's subject no longer exists. The one live concern it surfaced late — a census that authorises a batch of actions going stale mid-pass — is written into the deletion protocol as a re-derive rule.

## Fixed

### CLI-548 — `build marketplace` refuses a manifest its own loader would

A marketplace with no plugins, and one with an empty version, both produced a manifest the CLI writes and then refuses to read. Four end-to-end runs were pinning the defect rather than three: only one had the zero-plugin success as its subject and became the refusal, and the other three were each given a plugin rather than weakened.

### A warning raised during wizard hydration was lost off the top of the screen

Found by CLI-586's guard, and reported by the owner from a real `init` run after a probe across nine terminal sizes had failed to reproduce it — a fresh install has no skill that can be absent from its marketplace, which is why it stayed hidden.

`absentFromSourceWarning` was raised after the startup buffer had been drained, so it went to stderr under a frame that is exactly the terminal's height by construction. Height-independent: one failing spec runs at 60 rows and still lost exactly three lines. Fixed at the buffering window rather than at the call sites, so both warning arms and both `init` and `edit` are covered by construction.

### Three sites sent a private marketplace's own ids through the tunnel

A zod issue path joined over records keyed by a marketplace's ids, routed via Sentry's `tunnel` — through the very worker the catalogue fetch avoids on purpose. The reported path now keeps its first segment only; the path shown in the browser keeps the whole thing, because those two readers are not the same reader.

### A skill copy no longer aborts the whole run

One `ENOENT` had been ending the installation. The run continues and names the skill that stopped it.

## Removed

- The `init` hook's marketplace resolution, which resolved a source for a reader that no longer existed.
- 131 findings from `.ai-docs/agent-findings/`, with every citation repaired and their INDEX rows kept as the record.
