# Release 0.144.0 (2026-07-20)

`doctor` stops reporting a clean bill of health on genuinely broken installs, and `compile` stops silently dropping configured skills (D-253, D-254)

## Fixed

### D-253 — `doctor` was blind to four real failure states

**Uninstalled plugin skills went undetected.** After a plugin-mode skill was removed, `config.ts` still declared it and `enabledPlugins` was empty, yet `doctor`'s output was byte-identical to the healthy state — a planted inconsistency that produced no warning at all. Eject mode warned correctly in the same situation, so plugin-sourced skills had no verification whatsoever.

A new **"Plugins Installed"** check now verifies the plugin registry, grouped by each skill's own scope. It deliberately does _not_ add a disk check for plugin skills — those live in the registry, not under `.claude/skills/` — so the existing eject-mode check and its messages are unchanged.

**Healthy global agents were reported as orphans.** Run at home scope, `doctor` listed every compiled global agent as "not in config" in the same run that certified it compiled, because the orphan check classified the shared agents directory against project-scoped agents only.

**"Skills Resolved" reported "No skills configured" on a global-only install.** The check read the stack rather than the configured skills, so a populated `skills` array with no stack entries looked empty.

**The remediation tip pointed at a command that makes it worse.** For a skill missing from disk, `doctor` said to run `compile` — which has no skill-installation path and, per D-254, silently dropped the skill instead. The tip now states the diagnosis without prescribing a command that cannot fix it.

### D-254 — `compile` silently dropped configured-but-missing skills

A stack-referenced skill absent from disk was dropped from the recompiled agent with only a `--verbose` log, so the default output reported a clean recompile of an agent that no longer matched `config.ts`. The drop is now surfaced as a warning.

## Internal

- Expressive-TypeScript refactor applied to the remaining commands — `uninstall`, `update`, `validate`, `eject`, `search`, `build`, `new` — plus the permission checker and the init hook. Behaviour-preserving.
