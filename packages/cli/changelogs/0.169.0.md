# Release 0.169.0 (2026-10-15)

The terminal wizard is gone: a bare `init` or `edit` opens the editor, `init --from` installs what it builds, and
0.168.0 is the last release with the wizard (CLI-923, CLI-924)

**Before you upgrade.** The wizard is still available in 0.168.0: `npx agents-inc@0.168.0 init`. Some runs that used
to refuse now exit 0 (listed under CLI-923).

## Changed

### CLI-923 — `init` and `edit` open the editor

- **A bare `init` opens the editor where nothing is installed.** It prints `Build it at https://agentsinc.sh/editor`,
  opens the browser at a terminal and writes nothing. Over an installation it shows the dashboard. The dashboard's
  options are `Edit in the web editor` (runs `edit --ui`), `Compile`, `Doctor` and `List`.
- **A bare `edit` is `edit --ui`.** It publishes this installation to mint an id, prints `Shared as <id>` and opens it
  in the editor.
- **`init --marketplace <ref>` without `--from` opens the editor and prints one line about the marketplace.** Beside
  `--from` it still installs from that marketplace, which is the way to test local changes. The line:
  - a remote ref: `Add <ref> from the editor's Marketplace button.`
  - a local folder:
    `<ref> is a folder on this machine, which the editor cannot read — push it to GitHub, then add it from the editor's Marketplace button.`
- **Exit codes scripts may see change.** These now exit 0:
  - a bare `init` with no terminal and nothing installed (was 1);
  - a bare `edit` with no terminal (was 1);
  - `init --ui --marketplace <ref>` (was 2);
  - `init --marketplace <ref>` over an installation made from another marketplace (was 2).
- **`init` and `edit` help** describe the editor route, `--from` and `--marketplace` as above.
- **`new marketplace`'s last next step is now two steps.** Push the marketplace to GitHub and add it from the editor's
  Marketplace button. Or run `init --from <id> --marketplace <dir>` from a project to test local changes.
- **Hints that sent you to the wizard name a command that still exists.** A failed eject copy says to re-apply with
  `edit --from <id>`. `doctor`'s unowned-files tip names `init --from <id>`.
- **The editor's Install dialog.** When no id can be minted, its notes read
  `id unavailable — this command starts over in the editor` or
  `offline — this command starts over in the editor`.
- **Docs.** The site, the README and `CLAUDE.md` describe the CLI without the wizard. The pages also fix three
  sentences that were already false: `uninstall` without `--yes` exits 1, not 4; `list` is interactive; and the
  wording of an unreadable `config.ts`'s error.
- **Test harness.** Every e2e spawn door points the seed API at an unroutable address unless a spec names its own
  store, and `check-spawn-doors` holds every door to it. A spec had minted a real id on the live store.

### CLI-924 — the journeys page, re-run by hand

- **`user-journeys.md` describes the wizard-free product.** Rows 44, 44a, 44b and 23 cover a bare `init`, the
  dashboard, the Install dialog's no-id notes and a bare `edit`. The wizard's rows are gone. `spec-gates.test.ts`
  holds the page to the specs that remain.
- **Every row was run by hand on this tree, with the editor legs in Chromium.** The result was 52 PASS, 13 PARTIAL,
  2 FAIL and 1 N/A, and every failure was confirmed a second time. The record is
  `todo/plans/2026-10-15-manual-journey-run.md`. The 2026-10-01 record sits beside it.

## Removed

- **The terminal wizard:** its components, store, step logic, theme and six hooks. `zustand` is no longer a
  dependency.
- **`edit`'s hidden `--project-setup` and `--project-setup-marketplace` flags.**
- **`init`'s refusals of `--marketplace`** beside `--ui` and over another marketplace's installation.
- **`edit`'s "Remove them with 'agents-inc edit'" line.** No CLI route removes a skill the round trip does not own.
- **In `@workspace/compile` and the vendored matrix types:** `WizardResultV2` is now `InstallSelection` and
  `seedToWizardResult` is now `seedToInstallSelection`. `InstallSelection` drops `domainSelections`, `cancelled` and
  `unresolvableSkillIds`, and its `assignedStack` is required. `DomainSelections`, `CategorySelections` and
  `agentDefinedDomains` are gone.

## Fixed

- **`check-finding-citations` and `check-findings-frontmatter` pass again** after the 2026-10-14 findings prune. Nine
  older changelogs (0.145.0 to 0.163.0) and the trackers now name pruned findings as text instead of linking them,
  and the dangling-reference pin is empty.
