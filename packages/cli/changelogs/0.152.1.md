# Release 0.152.1 (2026-08-06)

The README's documentation links work again

## Fixed

### Every documentation link in the README resolves

The user guides and command reference existed twice — once under `docs/cli/` in the repository and once on the documentation site — with nothing keeping the two copies in step. The site is now the single source, and the duplicated originals are gone.

The README linked to the copies that were deleted, so its twelve documentation links broke. They point at the site's own files now and resolve again. If you followed a link from the 0.152.0 README and got a GitHub 404, this is why, and this release fixes it.

Nothing else about the CLI changes.

## Changed

### Two counts in the README were years out of date

It advertised "150+ skills across 8 domains" against a catalogue of **222 skills across 9 domains**, and its table of sub-agents listed 18 of the 23 that ship — `ai-developer`, `ai-reviewer`, `api-pm`, `api-tester` and `infra-reviewer` were missing. Both are corrected.
