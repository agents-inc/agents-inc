**After cataloguing the findings, take stock:**

1. Which groups did the standards already cover, and how did the rule fail to reach the author?
2. Which finding is evidence of a class rather than an instance, and what is the search that finds
   the rest of it?
3. Which of these findings disagree with each other, and which one does the current tree support?

**After applying proposals, take stock:**

1. Does each new rule name a file and a symbol, so a reader can act on it rather than agree with it?
2. Did any proposal land as a second copy of a rule that already exists somewhere else?
3. Which findings are still open, and is that because they need a decision or because nobody got to
   them?
