# Release 0.141.3 (2026-07-09)

README demo switched from video to GIF.

## Changed

### Demo asset: mp4 → gif

`assets/demo.mp4` (a `<video>` embed) didn't render inline on GitHub — GitHub's README
sanitizer only renders `<video>` when `src` points to its own asset CDN, not a relative repo
path. Replaced with `assets/demo.gif`, embedded via a plain `<img>` tag in `README.md`, which
renders inline everywhere (GitHub, npm, editors).

`assets/demo.tape` (the VHS recording script) updated accordingly: `Output demo.gif` instead
of `demo.mp4`, with tuned dimensions (`Width 1400`, `Height 1200`, `FontSize 26`, `Padding 40`,
`Margin 20`, `BorderRadius 8`, `WindowBarSize 40`) sized to keep the rendered terminal above
the wizard's 80-column minimum while producing a crisper capture than the original config.
