# Release 0.142.5 (2026-07-19)

Wizard scope-hotkey reliability fix plus E2E suite stability (no task tickets;
root-caused from the dual-scope E2E flake investigation).

## Fixed

- Wizard `s` scope-toggle race: `focusedSkillId` was seeded by a post-mount
  `useEffect` in CategoryGrid while the `s` hotkey handler reads it synchronously,
  so a keystroke arriving between the first paint and the effect flush acted on
  stale/null state (captured under load: the toggle landed on the wrong skill,
  displacing the focused one from its exclusive category). The store now seeds
  `focusedSkillId` synchronously — at hydrate (init and edit flows), on build-step
  entry, and on every domain transition — via the same `buildCategoriesForDomain`
  derivation the grid renders from; the redundant mount effect is deleted.

## Changed

- E2E suite capped at `maxWorkers: 16`: PTY-driven wizard tests are load-sensitive
  at full parallelism; the cap costs ~nothing in wall-clock (the suite is not
  parallel-bound past 16 workers) and reduces contention-induced flakes.
