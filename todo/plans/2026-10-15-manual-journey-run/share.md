The resulting `QUqv-Tz2` has no `description`, and neither does the `config.ts` it installs. `toSeedPayload` in `apps/editor/src/features/configure/lib/seed.ts` never writes the field. This is by design: `commands/share-refuses-ejected` "leaves edit --ui carrying an editor-added skill's bytes". The row text does not say which producer carries it back.
- **The `Open it:` link is still fixed to `https://agentsinc.sh/editor/`** under `AGENTS_INC_API_URL`, so a locally minted id cannot be opened from the printed line. Unchanged since 2026-10-01.
- **`~/.cache` is written even by runs that refuse.** The update check writes `~/.cache/agents-inc/version`. `init --from` refusals that load the public catalogue first also fill `~/.cache/agents-inc/sources/…` and `~/.cache/giget/…`. All of this is outside any installation, and journey 45's "no file written" holds for the cwd and the installation only (as noted on 2026-10-01).
- **`init --from` at `$HOME` still writes `name: 'agents-inc'`** into the global `config.ts`, while a project run's global side effect writes `name: 'global'` (13a, 32). Unchanged.
- **The 24(f) write-over refusal now prints with oclif's `›` gutter**, so the 2026-10-01 formatting note no longer applies.
- **CLI-923 hint re-read:** I checked the hints on this lane's paths that name bare `edit`/`init` against the new routes. `packages/compile/src/seed-to-config.ts` `absentSkillWarning` ("remove it with 'npx agents-inc edit'") is outside the spec's `src/cli` grep, but it still works.
