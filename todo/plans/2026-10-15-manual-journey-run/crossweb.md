**X1. From a project, `edit --from` names existing global sub-agents "Kept as installed", then rewrites them.** (journey 30)
Repro: `$S/repro-30.sh`. It POSTs `$S/payloads/30-installed.json` and `$S/payloads/30-edited.json` to the local worker (content-addressed, so they come back as `9YaG8OTT` and `EN5gz1ul`). It then runs `init --from` and `edit --from` in a fresh HOME and project, answering `y` in tmux. Wrong output:

--- after: pm.md mentions vitest: 2 line(s)

`keptAsInstalledGlobally`'s own doc comment says a global sub-agent the configuration tunes differently "stays as installed". In journey 23 the same list was truthful: Jotai, in an occupied one-of slot, did not land on the listed agents, and the run reported `9 unchanged`. Here Vitest, in a non-exclusive slot, did land on all four.
Suspected cause: the project-run merge joins the id's rows into kept global sub-agents per category slot, but the disclosure lists the whole sub-agent as kept, and the `Changes:` diff leaves out global agents whose rows were only joined.
